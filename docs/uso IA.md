### Uso de IA ###

Se usó IA de manera extensiva en el proyecto. De manera predominante para solucionar dudas, depuración de errores y como tutor.
En el backend se hizo uso de la IA a manera de prompts sin usar capacidades agenticas para internalizar el armado del proyecto se hizo uso sobretodo de ChatGPT.
En el frontend se usaron capacidades agenticas para el armado de clases de Angular con el IDE Antigravity de Google.
En el caso del backend, se elaboraron prompts para un armado paulatino del proyecto a partir de preguntas. En total se formularon alrededor de 60 preguntas. Dichas preguntas también tenían la intención de medir el conocimiento teniendo en cuenta la prueba. También se uso como tutor y para la elaboración de diagramas y parte de la documentación.
